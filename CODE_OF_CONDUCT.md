# Code of conduct

This project adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)
as its code of conduct. Everyone who takes part (in issues, pull requests, discussions and reviews) is expected to
follow it.

## Reporting

Report unacceptable behaviour to **conduct@your-domain.example**. The maintainers read every report, treat it in
confidence, and act on it as the Covenant's enforcement guidelines describe. A report about a maintainer goes to the
other maintainers.

# Support

- **A question, or how to do something:** start with the docs ([`wiki/`](wiki/README.md), and
  [Getting started](wiki/getting-started.md) and [Troubleshooting](wiki/troubleshooting.md) first). If they don't
  answer it, open an issue.
- **A bug:** open an issue with the **Bug report** form.
- **An idea or a missing feature:** open an issue with the **Feature request** form.
- **A security vulnerability:** never in an issue; report it privately as [SECURITY.md](SECURITY.md) says.
- **Contributing a change:** [CONTRIBUTING.md](CONTRIBUTING.md).

Support is best effort, from the maintainers. A service built from this template is supported by its own owner.

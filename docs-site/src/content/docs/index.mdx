## What it is

A template for a web service, ready to adapt into your own: a FastAPI backend and a Next.js frontend (an image each,
plus an optional WAF image), one Helm chart for every environment, and GitHub Actions that check every pull request
and build, sign, attest and deploy every release. The service name is a placeholder that one script replaces, and
the repository settings ship as a script too.

## Who it is for

- **A team starting a service** that wants the production controls in place from the first commit: signed images,
  admission, keyless deploys, a gated release.
- **A platform owner** who sets up the cluster, the edge and GitHub once, then lets each service follow the same path.
- **A contributor to the template**, whose change reaches every service built from it.
